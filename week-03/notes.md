## In My Own Words

**What's the difference between a file and a folder, and how do they form a tree together?**

```
A file is where information is stored, like a document, image, or log, while a folder is used to organize and hold files or other folders. Together, they create a tree structure because you start with a main directory and branch off into smaller folders and files. I think of it like the filing cabinet analogy from Lesson 1, where the folders are the labeled drawers and the files are the documents inside them.
```

**How does a Windows-style file path differ from a Linux-style file path?**

```
A Windows-style file path usually starts with a drive letter like C: and uses backslashes (\) to separate folders, while Linux uses forward slashes (/) and doesn't use drive letters. For example, Windows might show C:\Users\Documents, while Linux would show something like /home/archivist. Both help you locate files and folders, but the way the paths are written is different.
```
